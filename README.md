# 3D Developer Portfolio | MD Rifat Mohsin Tapader

An immersive, high-performance 3D portfolio website showcasing the engineering work, Android applications, and full-stack web platforms of **MD Rifat Mohsin Tapader** ([@Rifat-Profiles](https://github.com/Rifat-Profiles)), based in **Sylhet, Bangladesh**.

---

## 🌟 Key Highlights

- **Dynamic Island 3D Header**: Modern floating capsule navigation bar with a custom circular cut logo (featuring Sun God Nika Gear 5 artwork from Pinterest), live radar status indicator (`Sylhet, BD • Online`), and interactive Web Audio frequency equalizer.
- **Cinematic Color Grading**: Atmospheric obsidian base, hyper-neon cyan highlights, fiery crimson energy, and celestial violet accents.
- **Interactive 3D WebGL Canvas**: Built with **Three.js**, featuring an interactive holographic cyber core, orbital tech data rings, and a reactive 850+ particle field responsive to cursor tilt and touch gestures.
- **Interactive 3D Tech Constellation**: Rotatable 3D wireframe node sphere depicting synchronized mobile, web, and cloud architectures.
- **Featured Repositories & Real Projects**:
  - **[Nexload - Android Media Downloader APK](https://github.com/Rifat-Profiles/Nexload-Android-Downloader-APK)**: High-speed Android media utility built with Kotlin, Coroutines, and Material 3.
  - **[TaskFlow - Offline Productivity App](https://github.com/Rifat-Profiles/to-do-app)**: Offline-first productivity suite built with Jetpack Compose & Room DB.
  - **NovaSphere 3D Developer Portal**: WebGL 3D spatial web showcase with procedural Web Audio synthesis.
  - **PulseREST Microservice**: High-throughput REST API with authentication and caching.
- **Interactive Hacker Terminal / Dev Console**: Fully interactive CLI terminal emulator supporting commands like `help`, `about`, `skills`, `projects`, `nexload`, `taskflow`, `matrix`, `contact`, `clear`.
- **Procedural Web Audio Synthesizer**: Native Web Audio API sound generator delivering subtle sci-fi hover sweeps, typing clicks, and chime feedback without any external audio asset downloads.
- **3D Card Hover Physics**: Smooth perspective tilting on project cards using CSS 3D transforms.
- **Direct Contact & Inbox Integration**: One-click email copier with confetti celebration, mailto dispatch, and direct links to `rifatmohisn716@gmail.com`.

## 🚀 Getting Started

### 1. Clone & Install

```bash
git clone https://github.com/Rifat-Profiles/Rifat-Profiles.git
cd P1
npm install
```

### 2. Run Local Development Server

```bash
npm run dev
```

Visit `http://localhost:3000` to explore the 3D portfolio locally.

### 3. Production Build

```bash
npm run build
```

The optimized static production assets will be generated in `dist/`.
